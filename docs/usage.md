# 作品サイトの使い方

管理画面は [daisukeminowa.com/admin](https://www.daisukeminowa.com/admin) です。メールアドレスとパスワードでログインします。

## 追加・編集する

作品、展示歴、学歴は、どれも同じ手順です。

1. 左のメニューで、追加・編集したいもの（「作品」「展示歴」「学歴」）を開く。
2. 追加するときは「新規作成」を押す。編集するときは、一覧から選ぶ。
3. 内容を入れる。* の付いた項目は必須です。写真は、その場でアップロードもできます。
4. 「変更内容を公開」を押す。数秒でサイトに反映されます。

まだ見せたくないときは、公開せず「ドラフトを保存」を押してください。下書きはサイトに出ません。

## パスワードを変える

1. 右上の丸いアイコンを押す。
2. 「パスワードを変更」を押して、新しいパスワードを入れ、保存する。

## 困ったとき

- **写真を消したいとき**：作品で使っている写真は消せません。先に作品の写真を入れ替えてください。
- **パスワードを忘れたとき**：ログイン画面の「パスワードをお忘れですか？」は使えません。管理者に連絡してください。
- **ログインできなくなったとき**：パスワードを5回間違えると、10分ほどロックされます。待つか、管理者に連絡してください。
- **間違えて消したとき**：バックアップから戻せることがあります。そのまま管理者に連絡してください。
- **サイトの表示がおかしいとき**：どのページで何が起きたかを、管理者に連絡してください。
