# 作品サイトのデザインの作り直し

2026年11月24日時点

## 資料の目的

作品サイトの見た目を作り直した理由と、何が変わったかを説明します。

## 問題の説明

- **ページ**：作品のすぐ下に、本人写真、経歴、連絡先が続いていました。
- **本人写真**：作品と同じページに、作家の写真を大きく載せていました。
- **文字**：少し小さく、細すぎて読みにくくなっていました。

## 解決策の概要

- **ページ**：ホームは hero と作品だけにし、経歴は About、連絡先は Contact に移しました。
- **本人写真**：少し謎めいた存在にしておくため、作家の写真を消しました。
- **文字**：少し大きく、読みやすい太さの明朝体（しっぽり明朝）にしました。
